# Eric Update — Short Message

**Audience:** Eric  
**Purpose:** first contact / meeting pre-read  
**Target length:** ~250 words

## Suggested message

Hi Eric,

I wanted to send you a short update because the FCV reconstruction has changed character quite a bit.

What began as recovering the old empirical workflow has become the construction of a more explicit scientific measurement system. The main change is that source facts, measurement choices, geography/time semantics, and experiment choices are now kept separate rather than being embedded together in inherited analysis files.

That matters because the reconstruction exposed several scientifically consequential assumptions — for example, when sparse conflict data can legitimately mean zero, how project finance should behave when projects have multiple locations, and how survey geography and geospatial covariates should be interpreted when location or timing is uncertain.

The more interesting step is that we now have an **Africa Observability Lab** around the rebuilt system. Instead of stopping at a coefficient and asking whether it is significant, we can ask whether the empirical instrument is capable of recovering known external quantities and known injected signals in the first place.

The next gate is real-data commissioning: first reproduce authoritative DHS statistics with the rebuilt survey machinery, then characterize the detection frontier of the investment–conflict design, and then move to published external benchmarks.

I put together a very short scientific brief that explains the logic without the implementation history. I would especially value your reaction to the calibration/observability framing and to which substantive FCV relationships would be most useful to characterize once the instrument is commissioned.

Best,
Matías
